# Roadmap

This list separates what the alpha contains from what it does not. It is not a delivery schedule.

## In this alpha

- Unpacked Chrome extension and a loopback Fastify server.
- Text browser tasks with policy, confirmation, verification, and stop.
- Full-page chat, local SQLite memory, and document upload.
- OpenAI API and local Ollama planning.
- Optional local voice stack, and OpenAI realtime voice when an API key is set.
- Optional ChatGPT plan connection for open-source local use, full-screen only.
- One-shot scheduled tasks.
- Fixture site and scripted-planner acceptance tests.

## Not in this alpha

- Chrome Web Store listing.
- A hosted multi-user backend.
- Recurring schedules.
- A Google, Microsoft, or other account API. Calendar and mail are whatever those websites expose in the page.
- Reliable hands-off operation of every spreadsheet, mail client, or canvas app.
- Commercial redistribution of ChatGPT plan access. That needs OpenAI’s separate program.
- Remote telemetry.

## Next, if the alpha holds up

- Tighten spreadsheet and form recovery when a site rejects synthetic input.
- Document a Windows data directory after it is tested.
- Publish a private vulnerability reporting path on GitHub.
- Confirm the copyright name on the MIT license before the repository is public.
