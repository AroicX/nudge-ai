# Issue labels

Proposal only. These labels are not created on GitHub until the repository is public and the maintainer adds them.

| Label | Use |
|---|---|
| `bug` | A reproduced failure |
| `enhancement` | A feature request |
| `docs` | Documentation only |
| `security` | Public discussion of a hardening change. Vulnerabilities stay in private reporting |
| `good first issue` | A scoped change with a clear test |
| `alpha` | Known limit of the 0.1.0 alpha, not a regression |
| `provider` | OpenAI, Ollama, local voice, or ChatGPT plan |
| `windows` | Platform-specific setup that is still undocumented |
