# Changelog

## 0.1.0-alpha.1

First public-alpha candidate. Not yet published.

The extension version reported to Chrome is `0.1.0`. The release name is `0.1.0-alpha.1` because the manifest version cannot carry a prerelease tag.

Includes the browser task loop, full-page chat and local memory, OpenAI and Ollama providers, optional local voice, optional Sign in with ChatGPT for local open-source use, and the fixture acceptance tests. See [docs/release/0.1.0-alpha.1.md](docs/release/0.1.0-alpha.1.md).
